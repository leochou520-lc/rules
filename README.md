# 番茄小说去广告规则

基于 番茄小说 APK v7.3.5.32 逆向 + 实机验证 · 2026-11

## 支持客户端

| 客户端 | 文件 | 导入方式 |
|--------|------|----------|
| Shadowrocket | `shadowrocket.list` | 规则 → 导入远程规则 → 粘贴 raw URL |
| Loon | `shadowrocket.list` | 同上（格式兼容） |
| Surge | `shadowrocket.list` | 配置 → 规则 → 添加 RULE-SET |
| Stash | `stash/*.yaml` | rule-providers + RULE-SET |
| Egern | `egern.yaml` | rules → rule_set |
